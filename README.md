# Romano Assets support

This repository is the support channel for the Unity kits published by Romano Assets.

## Ask on Discord

For questions, quick help, ideas and sharing what you've built, join the [Romano Assets Discord](https://discord.gg/AmpBDxRAKu). Use #help for questions, #bug-reports for bugs and #feature-requests for ideas. Bugs confirmed there are tracked here.

## Report a bug

Open a [bug report](https://github.com/romanoassets/RomanoAssetSupport/issues/new?template=bug_report.yml). The form asks for everything needed to reproduce the problem. For ideas and improvements, use the [feature request](https://github.com/romanoassets/RomanoAssetSupport/issues/new?template=feature_request.yml) form. For setup and usage questions, use [Discussions](https://github.com/romanoassets/RomanoAssetSupport/discussions).

Please search [existing issues](https://github.com/romanoassets/RomanoAssetSupport/issues) first. Your problem may already have an answer.

## What to include

- The kit and its version.
- The exact Unity version, render pipeline and platform.
- What happened, and what you expected to happen.
- The shortest steps that reproduce the problem, ideally in a new empty project or one of the kit's demo scenes.
- The Console log, or the report from the kit's diagnostics tools if it has one.

Do not post passwords, keys or other private information. Report security issues privately as described in [SECURITY.md](SECURITY.md).

## Response time

Every new issue gets a first response within 2 business days.

## What support covers

Support covers bugs in the kits themselves and questions about setting them up and using them as documented. It does not include reviewing or debugging your own game code, or custom development.
